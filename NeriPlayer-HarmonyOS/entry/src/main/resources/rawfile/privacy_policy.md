# 隐私政策

生效日期：待定　　版本：v1.0.0-draft

一、我们是谁
NeriPlayer 是一个以 GPL-3.0 协议开源的个人音乐播放器项目，没有自建服务器，也没有面向本应用的后台服务。我们不为本应用运营任何账号体系或云端曲库。

二、我们收集哪些信息
本应用不收集、不上传、不共享你的个人信息。具体而言：
· 不内置任何统计、埋点、广告或崩溃上报 SDK；
· 不采集设备标识、通讯录、短信、通话记录、精确位置或相册内容；
· 你在应用内产生的播放记录、收藏、搜索历史、下载任务与设置项，全部只保存在本机的应用沙箱内。

三、你自行登录的第三方平台
在线播放能力依赖你在第三方平台（网易云音乐、Bilibili、YouTube Music 等）已有的账号授权。相关登录凭据（Cookie / Token）只保存在本机的系统级密钥库中，仅用于向对应平台发起你主动触发的请求，不会发送给本应用作者或任何第三方。
你与这些平台之间的数据处理适用各平台自身的隐私政策；本应用不代为收集，也无法读取你在这些平台上的账号数据。
你可以随时在「设置 → 账号与登录」中退出登录，退出即从本机删除对应平台的凭据。

四、你自行配置的同步服务
如果你启用了 GitHub 或 WebDAV 元数据同步，同步目标与访问凭据由你自行填写，数据直接在你的设备与你指定的服务之间传输，不经过本应用作者的任何服务器。可在「设置 → 同步」中清除相关配置。

五、权限用途
· 网络连接（ohos.permission.INTERNET）：向你选择的音乐平台请求搜索结果、歌单、音频流与歌词。
· 获取网络信息（ohos.permission.GET_NETWORK_INFO）：判断当前是 Wi-Fi 还是移动数据，以执行你设置的省流量策略与流量提醒。
· 允许后台运行（ohos.permission.KEEP_BACKGROUND_RUNNING）：在你切换到其他应用或息屏后继续播放当前歌曲，并在通知栏与锁屏保留播放控制。
本应用不申请存储、相册、麦克风、通讯录或位置权限。读取本地音频时使用系统文件选择器，仅能访问你当次选中的文件。

六、诊断记录
为便于你自查播放失败等问题，应用会在本机保留一个容量有限的诊断环形缓冲。这些记录默认不离开设备；只有你主动导出时才会生成文件，导出前会对请求头、Cookie、Token 与文件路径等敏感内容做脱敏处理。可在「设置 → 开发者模式 → 调试工具」中随时清空。

七、你的控制权
· 退出登录：删除本机保存的平台凭据。
· 清空记录：清空继续收听、搜索历史、下载任务与诊断记录。
· 清理缓存：在「设置 → 存储与缓存」中释放封面与音频缓存。
· 卸载应用：卸载会一并删除应用沙箱内的全部数据。

八、未成年人
如果你是未成年人，请在监护人的指导下使用本应用。

九、政策变更
本政策如发生重大变更（例如新增权限或改变数据处理方式），应用会在启动时重新征得你的同意。

十、联系方式
本项目通过开源代码仓库的 Issue 渠道接受隐私相关问询，仓库地址见「设置 → 关于」。
